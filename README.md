# java-filmorate

Схема базы данных находится в файле FilmorateSchema.png

# Описание: 
Есть 2 основные таблицы Film и User с описательными полями (дата рождения, имя и т.д.). 
Рейтинги фильмов вывел в отдельную таблицу Rating, связь с Film через ratingId.


Жанры фильмов также вывел в отдельную таблицу Genre. 
Связь с Film через отдельную таблицу-связку FilmToGenre. 
Это нужно для того, чтобы у одного фильма могло быть много жанров

Лайки в отдельной таблице Likes. Связь с Film и User через filmId и userId соответственно.

Функция друзей в отдельной таблице Friends. 
Для каждого юзера (userId) указан id его друга (friendId), а также третье поле (approved), которая указывает, подтверждена ли дружба.
